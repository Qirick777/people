# 구현 순서

## 이 게임의 핵심 (구현 판단 기준)

- 규칙은 기초 요소만 둔다. 개인 상태(특성, 충성, 불만, 허기, 재산), 물리적 세계, 기본 행동.
- 마을, 가문 사이 경쟁, 위기는 이 기초 요소가 겹쳐서 나와야 한다. 보너스 수치를 넣지 않는다.
- 특성이 결과를 좌우한다. 특성은 유전되고, 일의 성과와 짝 선택과 생존을 바꾼다.
- 플레이어는 한 가문을 이끈다. 목표는 혈통을 최대한 많이 불리는 것. 결정은 갈림길과 방침뿐이다.
- 수천~수만 명이 돌아가야 한다.

## 구현 원칙

1. **시뮬레이션 먼저, 화면은 나중.** 화면 없이 돌려서 재미있는 변화가 보여야 화면을 붙인다.
2. **시뮬레이션은 Godot과 분리한 순수 C#.** 엔진 없이 단위 테스트와 벤치마크가 돈다. 화면은 이 데이터를 읽기만 한다.
3. **단계마다 검증 장면을 만든다.** 그래프, 지도 이미지, 수치로 "의도한 현상이 저절로 나오는지" 확인한다.
4. **시드 고정.** 같은 시드면 같은 역사. 버그 재현과 비교 실험에 쓴다.
5. **성능 예산을 처음부터 잰다.** 단계마다 인구 1만/5만으로 틱 시간을 기록한다.

## 0단계. 기반

- Godot .NET 4.7.2로 전환, C# 솔루션 구성
  - `Sim/` 순수 C# 라이브러리 (Godot 의존 없음)
  - `Sim.Tests/` 단위 테스트
  - `Game/` Godot 프로젝트 (화면, 입력, UI)
- 고정 틱 루프, 시드 고정 난수, 배속과 자동 감속
- 속성별 배열(SoA) 저장소, 번호 + 세대 카운터 ID, 죽은 사람 기록 저장소
- 헤드리스 실행기: 인자로 시드, 인구, 연수를 받아 돌리고 CSV로 통계를 남긴다
- 그래프 생성 스크립트 (CSV → PNG)
- 저장소에 테스트 자동 실행(GitHub Actions)

**완료 기준**: 더미 5만 명을 1틱 돌리는 시간이 측정되어 기록된다.

**진행 상황**

## 1단계. 사람, 유전, 짝짓기, 번식

- 유전체: 대립유전자 쌍, 유무형(우성·열성)과 수치형(여러 쌍의 합), 성염색체 연관, 성별 영향, 돌연변이
- 표현형: 유전자 + 성장 환경(어릴 때 굶으면 덜 자람)
- 나이, 노화, 죽음
- 선호 특성, 짝 점수, 구애와 수락 확률, 일부다처와 기존 배우자 감점, 혈연 감점
- 임신 확률(짝 점수, 가구 잉여 식량, 나이), 여성 쿨타임, 출산 위험
- 가구: 식량과 재산 공유. 식량은 이 단계에서는 "가구 일손 × 땅 상태"로 단순 계산

**진행 상황**: 완료. 결과와 조정 내역은 `results/stage1.md`.
- [x] 족보와 혈연, 짝짓기, 임신·출산, 가구·분가·승계, 땅·농사·날씨, 굶주림
- [x] 검증 장면 4가지 그래프 (`docs/images/sim_stage1_*.png`)
- [x] 가구별 구성원·필지 목록, 성능 110 ms → 9.8 ms/일 (5만 명 시작, 끝 8.7만)
- [x] 다산 효과(쿨타임·쌍둥이), 근교약세와 열성 유전병 2개 (2단계와 함께)
- [ ] 남은 과제: 성장률 재조정(위기 후), 선호의 문화 전파

**검증 장면**
- 섬 하나, 10명 → 50세대. 인구, 특성 분포 변화 그래프
- 성선택: 다수가 키 큰 상대를 선호하게 두면 평균 키가 오르는가
- 근친: 고립 집단에서 열성 유전병이 늘어나는가
- 부: 부유한 남성이 자식을 더 남기고, 그 특성이 퍼지는가

## 2단계. 세계 생성과 농사

- 시드 → 대략 지도: 높낮이, 바다, 기온·강수, 강줄기, 호수, 생물군계
- 청크 세부 생성(필요할 때): 지형, 나무, 바위, 토양 비옥도
- 땅: 비옥도(경작하면 감소, 쉬면 회복), 물, 기후
- 계절(1년 = 4계절)과 농사 작업: 갈기·뿌리기, 김매기, 수확·운반·저장
- 저장과 부패, 날씨 변동, 흉년

**진행 상황**: 완료. 결과는 `results/stage2.md`.
- [x] 대략 지도(높낮이, 바다, 기온, 강수, 물길, 호수, 산·언덕), 필요할 때 만드는 청크 세부, 끊기지 않는 강
- [x] 마을(중심, 밭 반경, 분가·이주·새 마을), 지역 단위 구애
- [x] 숲 개간, 홍수, 지력 회복 목록
- [x] 검증 이미지 5장, 테스트 3개 추가(청크 순서 무관, 모든 땅이 바다로 흐름, 대륙 정착 결정성)
- [ ] 남은 과제: 마을 모양(지형·길), 강가 마을 후보, 지역별 날씨

**검증 장면**
- 시드별 지도 이미지 출력
- 사람들이 강가에 모여 사는가 (거주 밀도 지도)
- 흉년이 인구를 줄이고, 회복하는가

## 3단계. 개인 행동과 대규모 처리

- 욕구(허기, 피로, 안전, 재산, 관계)와 판단(유틸리티 AI). 판단은 드물게, 실행은 작업 묶음으로
- 생계 선택: 자작농 / 고용(급여)
- 공간 격자, 근처 사람 찾기
- 길찾기: 청크 단위 큰 경로 + 청크 안 세부 경로, 흐름장 공유, 경로 캐시
- 거리별 정밀도 3단계(근거리 매 틱 / 중거리 1시간 / 원거리 하루)와 단계 전환
- 정보 전달: 만나야 전해진다. 사람마다 "어느 시각까지 받았는지"만 저장
- 관계: 한 사람당 최대 150명, 약한 관계부터 잊음

**검증 장면**
- 3만 명, ×300 배속에서 틱 예산 안에 드는가
- 근거리 ↔ 원거리 전환 때 사람이 엉뚱한 곳에 나타나지 않는가

## 4단계. 화면

- 고정 각도 직교 카메라, 확대 단계, 화면 가장자리·드래그 이동
- 지형: 청크별 블록풍 메시. 물, 숲
- 사람: 블록풍. 한 명 = 메시 하나 + 정점 색. 근거리는 관절 회전 동작, 원거리는 MultiMesh
- 건물: 생성기로 만든 블록 조합. 같은 조각은 묶어서 그림. 원거리는 단순 모양
- 단면 보기(카메라 쪽 벽 낮추기, 층 선택)
- 시간 조작(일시정지, 배속), 인물 카드, 사건 기록(연대기)

**검증 장면**: 실제로 실행해서 마을이 살아 움직이는 것을 본다.

## 5단계. 건축, 소유, 경제

- 가구가 필요에 따라 집을 짓고 증축한다(일자 → ㄱ → ㄷ → ㅁ). 증축 규칙 자동화
- 재료 채집(나무, 돌)과 운반, 짓는 사람 손재주에 따른 품질과 속도
- 소유: 물건, 집, 땅의 주인 기록, 상속
- 물물교환, 급여(식량·물건)
- 문화 양식(지붕 경사, 색 등)을 배워서 전함

**검증 장면**: 화면 없이 100년 돌린 뒤 마을을 그려 보면, 집마다 다른 역사가 모양에 남아 있는가

## 6단계. 가문 플레이

- 혈통 판정, 가문 가구, 점수와 이정표
- 갈림길 선택 화면(혼인 후보, 진로, 분가, 상속, 이주, 위기)
- 가문 방침과 자동 결정, 알림 범위
- 평판, 원로, 마을 형성과 분열
- 족보, 혈통 지도, 인구 그래프, 연대기 화면
- 시작 상황, 도전 모드(같은 시드 100년)

**검증 장면**: 같은 시드에서 서로 다른 방침(다산 중시 / 재산 중시 / 장자 상속 / 균분)으로 100년 돌려, 결과가 의미 있게 갈리는가. 한 가지 방침이 늘 이기면 규칙을 고친다.

## 7단계. 마무리

- 건강과 전염병, 기술 일과 도제, 교환
- 저장·불러오기
- 밸런스, 성능 마감
