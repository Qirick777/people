# 검토 안내 (2026-10, O3까지)

O4(쿠데타, 내전, 독립)에 들어가기 전에 지금까지 넣은 것을 한 번 둘러보기 위한 안내다. 자세한 규칙과 숫자는 `spec.md` 22~31절에 있다.

## 시작하기

1. Godot에서 프로젝트를 열어 실행한다.
2. 처음 창에서 **자리 잡은 세계**(기본)를 고른다. 큰 지도에 220년을 돌린 세계라서 지배자, 봉신, 상단, 용병단, 신도회, 범죄가 다 있다. 만드는 데 1~2분 걸린다.
3. 다 만들어지면 **둘러보기** 창이 뜬다. 볼 만한 집 가운데 하나를 '맡기'로 고른다. '보기'는 그 집으로 화면만 옮긴다. 위 막대의 '둘러보기'로 언제든 다시 연다.

| 볼 만한 집 | 여기서 보면 좋은 것 |
|---|---|
| 가장 큰 지배자 | 재판, 다툼(내가 눈여겨보는 세력), 조직 창의 군대와 갈래, 봉토 맡기기·거두기 |
| 봉신 영주 | 주군을 섬기는 쪽. 다툼 창의 '나를 눈여겨보는 지배자', 주군의 요구. 주군 카드에서 거사 꾸미기와 독립 선언 |
| 무리 | 영주가 되기 직전. 단계 문턱, 의심 |
| 의심받는 세력 | 위 지배자의 반응(경고, 서약 요구, 진압, 서임)이 오는 쪽 |
| 도적 두목 | 숨긴 조직, 털기, 납치, 보호세 |
| 상단·용병단·신도회 우두머리 | 일과 회칙, 가르치기, 권위, 알려진 정도 |
| 장인 집 | 재화와 마을 값(집 카드) |
| 자리 없는 배운 사람의 집 | 지식인 동요 |
| 소작 집 | 밑바닥에서 시작하는 길 |

세계에 따라 없는 줄도 있다(이 세계에는 도적 두목과 소작 집이 안 잡힐 수 있다).

## 지금 숫자 (300년, 시드 1~4, 개척 세계)

- 인구 지표: 성인까지 생존 64~68%, 성인 평균 사망 나이 54.6~56.1세, 여성 출산 5.5~6.0명(목표 안). 300년 끝 사람 수 8천~1만 3천.
- 세력: 300년 끝 무리 2~23, 영주 3~9, 대영주 0~2, 군주 0~1.
- 범죄(250년, P4 때 측정): 2천~5천 건. 신고 51~78%, 신고된 것 가운데 잡는 비율 27~50%.
- 오름의 다툼(300년): 반응 7~63번. 공격적 지배자는 진압, 신중한 지배자는 서약 요구, 말솜씨 좋은 지배자는 서임을 많이 고른다.
- 조직(시드 2, 300년 끝): 상단 34, 용병단 26, 신도회 19, 도적 떼 8.
- 재화: 도구 갖춤 0.72~0.77, 의류 부족 6~10%, 시장 거래는 수확의 약 1.2%.
- 교육: 매끄러운 계승 138~245번, 억지 계승 129~635번, 자리 없는 배운 사람 27~396명.

## 알려진 문제

검토 뒤 고친 것은 `review_findings.md` 9장과 spec 32절에 있다. 남은 것:

| 문제 | 숫자 | 어디에 적어 둠 |
|---|---|---|
| 개척 세계에 소작·지주가 없다 | 300년 끝 자작농 97~98%, 땅이 차지 않는다 | spec 32.5. P8 생성기 |
| 선동과 체면 잃기가 AI 세계에 없다 | 300년 동안 0번 | spec 32.5 |
| '난립 → 경쟁 → 강자' 흐름은 아직 확인 못 했다 | 개척기 성장 구간이라 단계 수가 늘기만 한다 | plan_orgs 11장 |
| 큰 신도회가 300명 가까이 큰다 | 시드 2, 220년: 195명 | 아는 권위의 끌림 때문. 지켜본다 |
