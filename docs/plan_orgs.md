# 조직, 권위, 교육, 흡수 계획 (2026-10)

P5까지의 세력 틀 위에 조직을 다시 짠다. 대화에서 정한 것을 모았다. P6(학교)과 P7(다툼, 쿠데타, 독립)의 내용 일부가 여기로 옮겨 왔다.

## 1. 원칙

- 조직의 종류를 목록에서 고르지 않는다. 구체적인 일 몇 개와 회칙 세 개를 조합하고, 성격은 그 조합에서 나온다.
- 할 수 있는 일은 세력 규모에 따라 열린다(마일스톤). 자동 성장 규칙을 늘리지 않는다.
- 상한선과 할당으로 막지 않는다. 비용과 되먹임으로 드물게 만든다.
- NPC와 플레이어가 같은 부품을 쓴다.
- 사람마다 아는 것을 저장하지 않는다. 판단이 필요한 순간에 위치에서 계산한다.

## 2. 세력이 서고 줄어드는 흐름

- 흐름: 빈 땅에서 난립한다 → 경쟁하며 수가 준다 → 강한 조직만 남는다 → 맞설 수 없을 만큼 커지면 나머지는 복속한다.
- **자리 잡은 정도:** 마을마다 그 마을에 미치는 기존 세력의 권위(3장)를 해마다 잰다.
  - 낮으면(빈 땅) 새 세력이 쉽게 서고, 위의 의심도 늦다.
  - 높으면 새로 서기 어렵고, 크게 의심받고, 진압당하기 쉽다.
- **야심가의 길:** 야망이 큰 사람은 자리 잡은 정도를 보고 고른다. 빈 땅이면 스스로 조직을 세우고, 꽉 찼으면 기존 세력 안에서 자리(갈래 우두머리, 징수관, 측근, 봉신)를 노린다.
- 큰 세력이 상속이나 과확장으로 무너지면 그 자리가 다시 비어 신흥이 선다.

## 3. 권위

- 권위 = (자금 + 권력 + 무력) × (0.5 + 조직원 평균 충성)
  - 자금: 조직(우두머리 집)의 식량과 한 해 수입
  - 권력: 아래 집과 사람 수
  - 무력: 조직과 갈래의 싸움 힘
- 판단은 실제 권위가 아니라 '그 사람이 아는 권위'로 한다.

### 3.1 알려진 정도(조직마다 다섯 중 하나, 우두머리가 고른다)

| 수준 | 조직원이 아는 것 | 바깥이 아는 것 | 늘어나는 방식 |
|---|---|---|---|
| 완전 은폐 | 우두머리만 전체, 나머지는 자기 갈래만 | 모름 | 포섭만(직접 발로 뜀) |
| 일부 은폐 | 전체 | 모름 | 포섭 + 조직원 가족 소개 |
| 중립 | 전체 | 새어 나간 만큼 | 위 + 스스로 찾아옴(조금) |
| 공개 | 전체 | 전체(멀수록 흐림) | 위 + 스스로 찾아옴 + 보호를 바라는 집 |
| 완전 공개 | 전체 | 실제보다 크게 보임 | 위 + 조직원 가족이 저절로 소속원(국민) |

- 공개할수록 위의 의심을 빨리 받는다. 숨길수록 크기가 느리게 는다.
- **새어 나감(조직마다 0~1):** 조직이 클수록, 충성 낮은 조직원이 많을수록, 다른 조직에도 든 조직원이 많을수록, 조직원이 잡혀 심문당할수록 오른다. 중립은 저절로도 오른다. 1을 넘으면 공개 쪽으로 한 칸 내려간다. 다시 숨기기는 어렵다.
- **아는 정도 계산:** 공개 수준 × 그 사람의 위치(우두머리, 측근, 갈래원, 소속원, 땅 안 바깥사람, 먼 바깥사람). 사람마다의 차이는 사람 번호와 조직 번호의 해시로 ±20%를 준다(저장 없음). 위치로 설명되지 않는 앎(심문으로 알아낸 것 등)만 기존 비밀 장치에 적는다.
- 저장: 조직마다 공개 수준, 새어 나간 정도 둘.

## 4. 소속

- **일꾼:** 하위 조직(갈래)에 든 사람. 갈래의 일을 하고 몫이나 품삯을 받는다.
- **측근:** 최상위에 바로 딸린 사람 가운데 우두머리가 거느릴 수 있는 수만큼. 호위, 곳간, 갈래 우두머리 후보. 야심가가 세력 안에서 처음 노리는 자리.
- **소속원(국민):** 최상위에만 든 나머지. 조직 일은 하지 않고 평소 삶을 산다. 몫이나 세금을 내고, 보호받고, 충성이 권위가 되고, 갈래가 사람을 뽑을 때 먼저 불려 간다.
- **전환:** 하위 조직이 처음 생기는 순간 최상위의 일이 갈래로 넘어가고, 최상위에 남은 사람은 측근과 소속원이 된다. 하위 조직이 없으면 모두가 일꾼이다(털기만 하는 무리 = 도적 떼).

## 5. 일과 회칙

### 5.1 일

| 일 | 하는 것 | 열림 |
|---|---|---|
| 지킴 | 맡은 마을의 방어에 조직원 힘을 더한다 | 처음부터 |
| 털기 | 계절마다 이웃을 턴다. 정체가 드러날 수 있다 | 처음부터 |
| 돌봄 | 굶는 집에 식량을 나눠 은혜와 충성을 얻는다 | 처음부터 |
| 설교 | 마을 사람의 신앙을 올리고 신도를 모은다. 헌금이 들어온다 | 신앙 깊은 우두머리 |
| 포섭 | 남(남의 조직원 포함)을 몰래 내 편으로 들인다 | 처음부터 |
| 납치 | 사람을 잡아 몸값을 받거나 포로를 맞바꾼다. 성적인 거래와는 엮지 않는다 | 조직원 3명 |
| 보호세 | 근처 집에서 수확의 일부를 받고, 그 집들은 나를 섬긴다 | 조직원 5명 |
| 교역 | 남는 곡식을 다른 마을에 팔아 차익을 낸다. 길에서 털릴 위험 | 조직원 5명, 장사꾼 1명 |
| 호송 | 남의 교역을 지켜 주고 삯을 받는다 | 조직원 10명 |
| 용병 | 다른 세력에 싸움 힘을 빌려주고 삯을 받는다 | 조직원 10명 |
| 선동 | 남의 세력에서 그 지배자를 보는 눈을 깎는다 | 비밀 조직, 조직원 10명 |
| 유곽 | 스스로 일하기로 한 어른에게 손님을 잇고 보호하며 몫을 받는다. 동의한 어른만, 강압 없음 | 30집 넘는 마을 |
| 가르침 | 조직원을 가르친다(7장) | 처음부터(도제), 영주(학당) |

- 같은 일이라도 국가 아래에서 땅 전체를 대상으로 하면 이름과 범위가 바뀐다. 보호세는 받기로 한 집에서만 받지만 세금은 땅의 모든 집에서 받는다. 지킴은 경비대와 군대가 되고, 털기는 전쟁 중이면 징발이 된다.
- 이름은 가장 무거운 일에서 저절로 붙고, 플레이어가 바꿀 수 있다.

### 5.2 회칙(조직마다 셋)

- 누가 들어오나: 아무나, 혈족만, 신앙 깊은 자만
- 번 것을 어떻게 나누나: 우두머리가 다, 고르게, 조직에 쌓음
- 알려진 정도: 3.1의 다섯

### 5.3 조합의 예

- 설교 + 돌봄 + 공개 = 종교 집단
- 교역 + 호송 + 고르게 나눔 = 상단
- 포섭 + 선동 + 완전 은폐 = 전복 세력
- 유곽 + 보호세 = 포주 조직
- 용병 + 지킴 = 용병단
- 털기 + 납치 + 일부 은폐 = 도적단

### 5.4 체면과 필요(AI의 판단)

- 높은 단계가 드러내 놓고 낮은 단계의 일(털기, 납치)을 하면 권위와 명예가 깎인다. 숨겨서 하면 깎이지 않지만 새어 나갈 위험이 있다.
- AI는 처지에 맞는 일을 고른다. 돈이 모자란 나라는 세금부터 손보고, 털기는 공격적이고 곤궁한 우두머리만 숨겨서 한다.
- 지배자 땅의 자경단은 인정받으면 경비대로 흡수된다. 자경단은 지배자가 지켜 주지 않는 마을에서만 생긴다.

## 6. 국가(최상위 세력)의 역할과 단계별 열림

- 국가는 일을 하지 않는다. 다섯 가지를 쥔다.
  1. 땅: 어느 마을이 내 땅인지
  2. 법: 세율, 벌의 세기, 누가 국민인지
  3. 곳간: 갈래가 번 것을 모으고 품삯을 나눔
  4. 자리: 갈래 우두머리를 앉히고 내림, 봉토와 칭호
  5. 바깥: 전쟁, 동맹, 섬김

| 단계 | 새로 열리는 것 |
|---|---|
| 모임(조직원 3명) | 지킴, 털기, 돌봄, 설교, 포섭, 납치, 회칙, 알려진 정도 |
| 무리(아래 5집) | 보호세, 교역, 갈래 나누기, 재판 |
| 영주(아래 20집) | 땅(마을 단위), 세금, 경비대, 학당, 분봉, 호송, 용병 계약 |
| 대영주(아래 100집) | 봉신 거느리기, 학교, 선동(남의 땅), 법(세율, 국민 범위) |
| 군주(아래 400집) | 서임하기, 대학, 전쟁 선포 |

## 7. 교육

- 교육이 만드는 것
  - 능력: 무예, 글, 장사, 농사(기존 도제 학습 공식)
  - 충성: 조직에 대한 충성. 종교 조직은 신앙도
  - 이음: 우두머리가 아는 것(조직원, 연줄, 곳간, 비밀)을 후계자에게 넘김
- 갈래마다 고른다: 무엇을(무예, 글, 장사, 교리, 이음), 얼마나(조직원 시간의 0~30%). 가르치는 만큼 갈래의 일이 준다.
- 규모별 방식: 모임·무리는 도제(우두머리나 측근이 한두 명), 영주는 학당, 대영주 이상은 학교·대학.
- **이음과 후계:** 갈래마다 후계자 한 명과 이음 값(0~1).
  - 충분하면 후계자가 그대로 잇는다.
  - 모자라면 힘센 사람이 억지로 잇고, 권위가 떨어지고, 충성이 흩어진다.
  - 완전 은폐 조직은 우두머리만 알던 갈래가 끊겨 떨어져 나간다.
- **큰 조직은 이음을 기록으로 대신한다:** 공개된 큰 조직은 글을 아는 관리가 충분하면 이음이 저절로 찬다. 그래서 AI 국가는 이음 대신 글을 가르친다.
- **지식인 동요:** 해마다 배운 사람 수를 자리 수(갈래 우두머리, 징수관, 관리, 선생)와 견준다.
  - 자리를 얻은 배운 사람은 충성이 오른다.
  - 못 얻은 배운 사람은 불만이 쌓여 충성이 떨어진다. 전복 조직의 포섭 1순위가 되고, 선동과 소문을 잘하고, 덮은 사건·무거운 세금·진압에 크게 반응한다.
- 저장: 갈래마다 후계자, 이음 값, 가르칠 것, 비중.

| 길 | 쓰는 것 |
|---|---|

| 2. 상단 | 글과 장사, 교역과 호송 |
| 3. 용병단 | 무예 많이, 용병 |

## 9. 기존 세력 흡수

1. **위에서 누르기(복속):** 서약 요구, 끌어들이기, 진압으로 상대 세력을 내 하위 세력으로 만든다. 상대 수장은 남는다(있음).
2. **안에서 먹기(쿠데타):** 세력은 그대로, 꼭대기만 바뀐다.
   - 준비: 내 조직원을 상대 세력의 갈래, 특히 군대 갈래 우두머리와 측근에 양다리로 심는다(포섭).
   - 새어 나감: 준비하는 동안 해마다 들킬 확률. 들키면 상대 수장이 숙청한다.
   - 거사: 상대 갈래 우두머리마다 편을 고른다. 기준 = 내가 아는 권위 × 그쪽 충성을 두 쪽에 견준다. 신중하면 확신이 클 때만 움직이고, 야심가는 덜 따지고, 광신자는 옛 수장 곁에 남는다. 갈래는 우두머리를 따라 통째로 움직인다.
   - 결과: 크게 이기면 내가 수장. 땅, 법, 갈래, 이름이 남는다(내 조직을 그 안에 넣을지, 이름을 바꿀지는 플레이어가 고른다). 비등하면 내전으로 둘로 쪼개진다(독립). 지면 나와 내 편이 처형되거나 쫓겨난다.
   - 정당성: 찬탈은 '스스로 섬'처럼 충성이 덜 오른다. 옛 수장의 혈족이나 혼맥이면 덜 깎인다.
3. **혼인과 상속:** 지배 가문과 혼인해 상속권을 얻는다(기존 상속 규칙).
4. **머리 위로:** 상대 세력의 주군에게 서약해 그 자리를 받는다(있는 기능을 넓힘).

## 10. 정예 제어(막지 않고 비싸게)

1. 글과 교리는 서로 깎는다: 글을 많이 배운 사람은 광신의 의심이 빨리 쌓인다.
2. 광신은 우두머리를 직접 겪어야 생긴다: 교리 교육만으로는 충성이 0.8까지만 오른다. 광신(0.9)은 우두머리를 보는 관계가 아주 높아야 하는데, 우두머리가 가까이 둘 수 있는 사람은 거느릴 수 있는 수뿐이다.
3. 재능과 나이: 무예는 힘과 손재주, 글은 지능이 받쳐야 하고, 배울 수 있는 나이가 한정된다. 둘 다 높은 사람은 드물다.
4. 정예는 일을 하지 않는다: 교육 비중이 큰 갈래는 일을 못 하니 곳간이 먹여 살려야 한다.

결과: 큰 투자로 10~20명짜리 친위대는 가능하지만, 그 이상은 효율이 급격히 떨어지고 주변의 의심을 산다.

## 11. 균형 지표(최종 맞춤은 P7·P8 뒤)

| 지표 | 범위 |
|---|---|
| 큰 세력 셋이 차지한 집 비율 | 50~85% |
| 100년 동안 지배자 집안이 아니던 집이 영주 이상이 된 수 | 1,000집당 1~3 |
| 100년 동안 꺾이거나 쪼개진 독립 세력 비율 | 15~40% |

개척기(인구가 폭발적으로 느는 때)의 숫자로 맞추지 않는다. 생성기로 만든 안정된 세계에서 맞춘다.

## 12. 구현 순서

| 단계 | 내용 |
|---|---|
| O1 (들어감, spec 28절) | 소속 전환(일꾼, 측근, 소속원), 알려진 정도 5단계와 새어 나감, 권위와 아는 권위 계산, 자리 잡은 정도, 야심가의 길, 공개 수준에 따른 확대 방식 |
| O2 (들어감, spec 29절) | 일 넓히기(보호세, 설교, 교역, 호송, 용병, 유곽, 선동, 납치), 회칙, 체면, 단계별 열림, 조직 창 |
| O3 | 교육(가르칠 것과 비중, 이음과 후계, 기록, 지식인 동요, 광신 제어) |
| O4 | 흡수와 쿠데타, 내전과 독립, 균형 진단(realmdiag). 기존 P7과 합친다 |
| P8 | 완성된 세계 생성기와 모드, 균형 맞춤 |

## 13. 뒤로 미룬 것
