## 구현한 것

### 대륙 생성 (`WorldGen.cs`, `WorldMap.cs`)
- **대략 지도** (48 × 48칸, 한 칸 = 청크 하나 = 256 m): 프랙털 노이즈 − 가장자리 낮춤으로 섬 대륙. 약 42%가 바다.
  웅덩이 메우기(priority flood)로 모든 땅이 바다로 흐르게 하고, 깊게 메워진 곳은 호수. 남쪽이 따뜻하고 높으면 춥다.
  빗물 흐름을 높은 칸부터 누적해 강줄기를 정한다.
- **산과 언덕**: 육지 높이 상위 10%는 산, 상위 25%는 언덕.
- **청크 세부** (32 × 32 타일, 타일 = 필지 = 8 m): 필요할 때 만든다. 높낮이·기온·강수를 보간하고 잔노이즈로 숲·풀밭·늪 경계를 만든다.
  강은 대략 지도의 물길을 2차 곡선으로 그려서 청크 경계를 넘어 끊기지 않는다. 여유 테두리(8 타일)까지 계산해 물까지 거리를 구한다.
- **비옥도**: 풀밭 0.85, 숲 0.95(개간 후), 언덕 0.6, 늪 0.5 × 기온 보정 + 범람원(물에서 4 타일 안) 최대 +0.4 + 잔노이즈.
- 같은 시드, 같은 좌표면 청크를 어떤 순서로 만들어도 같다(테스트).
- 대륙 전체 생성 약 1.5초. 정착 실행에서는 사람이 간 곳만 만든다(250년 동안 2,304개 중 350~470개).

### 마을
- 마을은 중심이 있는 단위다. 집은 중심에서 4 + 0.7 × √가구 수 타일 안에 모이고, 밭은 중심에서 24 타일(약 200 m) 안에서만 잡는다.
- 분가할 때: 마을에 빈 필지가 4개 이상이면 마을 안. 아니면 1.3 km 안의 빈 땅 있는 다른 마을, 또는 다른 마을에서 450 m 이상 떨어진 새 마을 자리(둘레 좋은 빈 땅 + 물 가까움) 중 나은 곳. 다 안 되면 본가 땅을 나눈다.
- 구애 상대는 주변 약 3 km(128 타일 칸 3 × 3) 안에서만 찾는다.

### 농사
- 숲 필지는 첫해에 개간만 하고 수확이 없다.
- 홍수: 강이 흐르는 대략 칸마다 해마다 5%. 물에서 2 타일 안 밭은 그해 수확 0, 대신 기본 비옥도 +0.03.
- 지력: 부친 땅만 줄고, 줄어든 땅만 회복 계산(목록으로 관리).

| 항목 | 목표 | 결과 |

| 성인 평균 사망 나이 | 55~65세 | 55.5~56세 |
| 45세까지 산 여성의 출산 | 5~7명 | 6.4~6.8명 |

| 마을 | - | 45~71개, 가장 큰 마을 107~123가구 |
| 새로 생긴 마을 / 이주 | - | 50~87개 / 550~1,180가구 |

1단계의 작은 섬과 달리 개척할 땅이 있어서 북적임이 덜하고, 목표 범위에 모두 들어왔다.

### 흉년 (`sim_stage2_famine.png`)

| | 평년 | 흉년(날씨 < 0.75) |
|---|---|---|
| 다음 해 인구 증가 | 2.4~2.7% | −0.4~0.8% |
| 굶주림 사망 (천 명당) | 3.3~4.9 | 11~16 |
| 출생 (천 명당) | 47~51 | 28~39 |

흉년이 들면 굶어 죽는 사람이 3~4배가 되고 아이가 덜 태어나 성장이 멈췄다가, 평년이 오면 다시 는다.

| 측정 | 결과 |

## 남은 과제

1. 마을 밭이 완전한 원 모양이다. 땅 좋음과 거리로 고르니 결국 원을 꽉 채운다. 지형(숲 개간 비용, 경사)과 길을 넣으면 자연스러워진다.
2. 물가 쏠림이 중간 정도(2~2.6배). 마을 자리를 24곳만 무작위로 보고 고른다. 강줄기를 따라 후보를 더 주면 강가 마을이 늘 것이다.
3. 기후 차이가 작다. 날씨가 대륙 전체에 하나뿐이다. 지역별 날씨를 넣으면 흉년이 마을마다 달라지고, 다른 마을과 식량을 주고받을 이유가 생긴다(5단계 장사와 연결).
4. 1단계의 성장률 문제(땅이 남으면 연 3%대)는 그대로다. 전염병을 넣은 뒤 다시 맞춘다.
