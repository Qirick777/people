# 사람 외형

좀보이드처럼 단순하고 간결하게 만든다. 사람마다 옷, 머리 모양, 색, 키, 체격만 다르다.

시안 이미지: `docs/images/human_*.png`
시안 코드: `prototypes/human_look/`

## 구성

| 부위 | 만드는 방식 |
|---|---|
| 몸 | 부위별 저폴리 메시(머리, 목, 몸통, 팔, 손, 다리, 발). 단면 10각. |
| 얼굴 | 이목구비를 그리지 않는다. 피부색만 칠하고 메시는 코 하나만 둔다. (확정) |
| 옷 | 몸통·팔·다리 텍스처로 그린다. 치마형 옷(튜닉 자락, 드레스, 로브)과 망토만 별도 메시. |
| 머리카락 | 덮개 메시 + 뒷머리 메시. 모양: 짧은 머리, 긴 머리, 올림머리, 땋은 머리, 대머리, 삭발(수도사) |
| 수염 | 짧은 수염, 긴 수염 + 콧수염 |
| 쓰개 | 두건(코이프), 철모, 등에 내린 후드 |

## 특성이 외형에 바로 드러난다

- 키와 체격 특성이 메시 크기를 바꾼다. "겉으로 보이는 특성"이 실제로 눈에 보인다.
- 피부색, 머리색은 유전 특성이다. 부모를 닮은 아이가 나온다.
- 옷은 직업과 재산을 보여 준다. 귀족은 염색 천과 금색 장식, 농민은 염색하지 않거나 흙빛 천.
- 병사는 섬기는 영주의 색을 겉옷(타바드)에 입는다. 멀리서도 소속이 보인다.

## 옷 시안 목록

농부(남), 농부(여, 앞치마), 대장장이(가죽 앞치마, 걷은 소매), 병사(누빔 갑옷, 영주 색 겉옷, 철모),
귀족(남, 더블릿, 망토), 귀족(여, 가운, 금색 띠), 수도사(로브, 끈 허리띠, 후드), 아이

색: 생마, 갈색, 적갈색, 꼭두서니 빨강, 대청 파랑, 초록, 회색, 검정, 금색 장식

## 확정 사항

- 이 방향으로 확정. 눈, 눈썹, 입은 넣지 않는다.
- 동작은 나중에 만든다.

## 이후 작업

2. 실제 게임용으로 바꿀 때:
   - 부위 메시를 사람 한 명당 하나로 합친다. 그리기 횟수가 준다.
   - 옷 텍스처는 사람마다 새로 그리지 않는다. 회색조 무늬 텍스처 몇 장 + 색 값으로 셰이더에서 칠한다.
     그래야 수천 명이 같은 재질을 공유해서 묶어 그릴 수 있다.
   - 멀리 있는 사람은 MultiMesh + 정점 애니메이션 텍스처로 그린다. (`architecture.md` 원칙 8)
