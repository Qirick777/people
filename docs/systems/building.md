# 건축

목표: 적은 디자인으로 수많은 결과를 낸다. 부자연스럽지 않아야 한다. 오두막부터 정부 청사, 성까지 같은 시스템으로 만든다.

## 4층 구조

```
문화 양식 (지붕 경사, 장식, 색, 선호 재료)
   ↓
단지 (여러 동 + 담 + 마당)          ← 성, 청사, 부농 저택
   ↓
동 (직사각형 블록들의 조합)          ← 집 한 채
   ↓
블록 (직사각형 하나 + 층수 + 지붕)
   ↓
모듈 (벽, 창, 문, 모서리, 지붕 조각, 탑, 성가퀴)
```

## 1. 모듈

- 격자 위에 놓는 3D 조각. 벽은 칸의 경계에 선다. (좀보이드 방식)
- 종류: 벽(민벽, 창, 문), 모서리, 바닥, 계단, 지붕 조각(맞배, 우진각, 외쪽), 굴뚝, 기둥, 탑, 성가퀴
- 재료별로 한 벌씩: 나무, 돌, 흙벽돌, 초가, 기와 ...
- 이것만 아트로 만든다. 나머지는 전부 조합이다.

## 2. 블록과 동

**블록 = 직사각형 하나.** 층수와 지붕 형태를 가진다.

**동 = 블록 조합.** 몇 개의 틀에서 시작한다. 이 틀이 "디자인 몇 개"다.

| 틀 | 모양 | 주 용도 |
|---|---|---|
| 일자 | ㅡ | 오두막, 작은 집 |
| 꺾임 | ㄱ | 보통 집 |
| 날개 | ㄷ | 큰 집, 청사 |
| 중정 | ㅁ | 저택, 청사, 수도원 |
| 탑 | 좁고 높은 □ | 망루, 성탑 |

- 모양을 직사각형 블록의 조합으로 제한한다. 그래야 지붕이 항상 자연스럽게 풀린다.
  복잡한 다각형 지붕은 절차 생성에서 가장 자주 어색해지는 부분이다.
- 블록마다 자기 지붕을 얹는다. 작은 블록의 지붕은 큰 블록 벽에 기대어 붙인다(덧집). 실제 옛 건물이 이렇게 생겼다.

## 3. 방 배치

건물은 겉모양이 아니라 **필요한 방 목록**에서 출발한다.

| 건물 | 방 목록 예 |
|---|---|
| 가난한 집 | 한 칸(부엌 겸 침실) |
| 보통 집 | 부엌, 침실 × 식구 수에 맞게, 창고 |
| 대장장이 집 | 위 + 작업장 |
| 정부 청사 | 집무실, 기록실, 회의실, 창고, 대기실 |
| 성 | 위 + 영주 거처, 병영, 무기고, 곡물 창고, 성벽, 탑 |

1. 방 목록의 총 면적으로 틀과 크기를 고른다.
2. 블록을 방으로 나눈다. 공용 공간(부엌, 회의실)을 입구 쪽에 둔다.
3. 방마다 문을 이어 모든 방에 갈 수 있게 한다.
4. 창은 바깥벽에만, 문은 길 쪽으로 낸다.

방은 시뮬레이션에서 실제 공간이다. 잠자리, 창고 용량, 작업대가 방에 있다.

## 4. 변수

같은 틀과 방 목록에서 아래 변수가 결과를 갈라놓는다.

| 변수 | 정하는 것 |
|---|---|
| 재료 | 주변에서 구할 수 있는 것. 숲 근처는 나무, 바위산 근처는 돌. |
| 기후 | 눈 많은 곳은 지붕 경사가 가파르다. 추운 곳은 창이 작다. 더운 곳은 처마가 깊다. |
| 지형 | 경사지는 돌 기단이나 기둥을 높인다. 물가는 기둥 위에 짓는다. |
| 방향 | 길이나 강을 향한다. |
| 재산 | 층수, 장식, 좋은 재료, 담과 마당 |
| 문화 양식 | 지붕 모양 선호, 장식 무늬, 색 |
| 시간 | 증축, 낡음, 보수 흔적, 폐허 |

## 5. 자라는 건물 (자연스러움의 핵심)

건물은 한 번에 완성되지 않는다. 사람의 필요에 따라 자란다.

- 식구가 늘고 재료가 있으면 블록을 덧붙인다. 일자 → 꺾임 → 날개 → 중정.
- 성도 같은 방식으로 자란다. 실제 성도 대부분 이렇게 생겨났다.
  ```
  영주의 집 → 담 → 망루 → 돌로 다시 쌓기 → 성벽 → 탑 추가 → 성
  ```
- 청사도 영주 집의 한쪽 방에서 시작해, 관리가 늘면 따로 떨어져 나온다.
- 그래서 같은 틀에서 출발해도 집마다 역사가 다르고, 그 역사가 모양에 남는다.
- 버려진 집은 낡고 지붕이 무너져 폐허가 된다. 망한 마을이 지형에 흔적으로 남는다.

## 6. 문화 양식

- 지붕 경사, 장식, 색, 선호 재료는 문화 특성이다. 집 짓는 사람이 배워서 전한다.
- 마을마다 양식이 조금씩 달라지고, 멀어질수록 더 달라진다.
- 이주와 정복으로 양식이 섞인다. 정복자의 성과 원주민의 집이 다른 모양으로 남는다.

## 7. 자연스러움 규칙

생성 결과가 아래를 어기면 버리고 다시 만든다.

- 위층은 아래층 범위를 벗어나지 않는다.
- 지붕이 모든 블록을 덮는다.
- 모든 방에 문으로 갈 수 있다. 입구는 길 쪽이다.
- 한 건물의 재료 조합은 2종까지. (돌 기단 + 나무 위층 같은 흔한 조합만)
- 이웃 건물과 벽이 붙지 않거나, 붙는다면 창이 없는 벽끼리 붙는다.

## 8. 짓기

- 설계는 착공할 때 정해진다. 짓는 과정은 시뮬레이션의 실제 일이다.
- 재료를 실어 오고, 기초 → 벽 → 지붕 순서로 모듈이 하나씩 놓인다. 짓다 만 집이 보인다.
- 짓는 사람의 손재주와 경험이 속도와 품질을 정한다. 품질이 낮은 집은 빨리 낡는다.

## 9. 화면

- 좀보이드처럼 카메라 쪽 벽과 지붕을 걷어 내 안을 보여 준다. 모듈마다 잘린 모양을 함께 만든다.
- 근거리: 모듈 단위로 그린다. 같은 모듈은 MultiMesh로 묶는다.
- 원거리: 블록마다 상자와 지붕 하나로 합친 단순한 모양.
- 아주 멀리: 마을 덩어리.

## 10. 데이터

- 건물 = 블록 목록 + 방 목록 + 변수 + 시드.
- 모듈 배치는 이 데이터에서 매번 똑같이 다시 만든다. 모듈 하나하나를 저장하지 않는다.
- 저장 크기가 작고, 수천 채여도 부담이 없다.
