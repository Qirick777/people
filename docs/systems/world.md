# 세계 생성과 탐사

## 생성

- 시드 하나로 자연 전체가 정해진다. 같은 시드면 같은 세계가 나온다.
- 두 단계로 만든다.
  1. **대략 지도**: 시작할 때 넓은 범위를 낮은 해상도로 만든다. 한 칸이 청크 하나다.
     높낮이 → 바다와 육지 → 기온과 강수 → 강줄기(높은 곳에서 바다까지 물길 계산) → 호수(물이 고이는 움푹한 곳) → 생물군계(숲, 초원, 늪, 산지)
  2. **세부**: 청크가 필요해질 때 대략 지도를 바탕으로 세부 지형, 나무 한 그루 한 그루, 바위, 토양 비옥도를 만든다.
- 강이 대략 지도에서 먼저 정해지므로 청크 경계에서 끊기지 않는다.
- 세부 생성도 시드와 청크 좌표만으로 정해진다. 언제 생성해도 같은 결과가 나온다.

## 생성 시점과 앎은 따로다

| 구분 | 기준 | 범위 |
|---|---|---|
| 세부 생성 | 누구든(어느 영지 사람이든) 청크 근처에 오면 | 세계 공통 |
| 지도에 보임 | 그 영지 사람이 보고 돌아와 보고해야 | 영지마다 다름 |

- 플레이어 지도에는 내 사람이 본 곳만 나온다.
- 본 사람이 돌아오거나 전령을 보내야 지도에 올라간다. (조직의 정보 전달 원리와 같다)
- 오래 가지 않은 곳은 정보가 낡는다. 그사이 숲이 베이거나 다른 영지가 마을을 세웠을 수 있다.

## 탐사

- 세계를 넓히는 건 사람이다. 플레이어는 묶음에 탐사 임무를 주고 보낸다.
- 탐사원은 실제로 걷고, 먹고, 다치고, 길을 잃는다. 식량을 들고 가야 하고, 멀리 갈수록 보급이 필요하다.
- 탐사원의 특성이 결과를 바꾼다. 눈썰미가 좋으면 자원과 위험을 더 많이 알아 온다. 체력이 좋으면 멀리 간다. 겁이 많으면 위험한 곳 앞에서 돌아온다.
- AI 영지도 같은 방식으로 탐사하고 퍼진다. 떠도는 무리, 이주민도 땅을 연다.
