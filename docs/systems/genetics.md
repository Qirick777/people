# 유전

## 기본 방식 (멘델식)

- 특성마다 유전자 한 쌍(대립유전자 두 개)을 가진다.
- 자식은 아버지의 쌍에서 하나, 어머니의 쌍에서 하나를 무작위로 받는다.
- 유전자형(가진 유전자)과 표현형(겉으로 드러난 특성)을 나눈다.

## 특성의 두 종류

| 종류 | 예 | 방식 |
|---|---|---|
| 유무형 | 재능 하나, 색맹, 특정 체질 | 유전자 한 쌍. 우성과 열성이 있다. |
| 수치형 | 키, 힘, 지능, 눈썰미 | 유전자 여러 쌍의 합. 각 쌍은 위와 똑같이 무작위로 받는다. |

- 수치형은 여러 쌍을 합하므로 자식이 대체로 부모 사이에 오되, 가끔 양쪽보다 뛰어나거나 못한 아이가 나온다.
- 우성이 별도 규칙 없이 자연스럽게 작동한다.

## 선호 특성

- 상대의 어떤 특성을 좋아하는지도 유전 특성이다. 수치형과 같은 방식으로 물려받는다.
- 짝 고르기에 쓴다. → `family.md`

## 우성과 열성

- 열성 특성은 두 유전자가 모두 열성일 때만 드러난다.
- 그래서 특성이 한 세대를 건너뛰어 손자에게 다시 나타난다. "할아버지의 재능이 손자에게" 같은 이야기가 저절로 생긴다.
- 보인자(드러나지 않지만 유전자를 가진 사람)는 겉으로 알 수 없다.
  정부도 직접 확인하지 못하고, 족보를 보고 추정만 할 수 있다. (특성 인지 시스템과 연결)

## 성별 발현

두 가지를 둔다.

| 방식 | 내용 | 예 |
|---|---|---|
| 성별 영향 | 같은 유전자라도 성별에 따라 드러나는 정도가 다르다. | 체격, 근력의 기본 차이 |
| 성염색체 연관 | 유전자가 성염색체에 있다. 남자는 X가 하나라서 열성이 바로 드러난다. | 색맹처럼 남자에게 훨씬 많이 나타나는 특성 |

## 돌연변이

- 유전자를 물려줄 때 아주 낮은 확률로 바뀐다.
- 새 특성이 드물게 생겨나는 통로가 된다.

## 환경

- 유전자는 가능성의 범위만 정한다. 자라는 환경이 실제 값을 정한다.
- 어릴 때 굶으면 키와 힘이 덜 자란다. 배우지 못하면 지능이 있어도 기술이 낮다.
- 그래서 좋은 혈통도 잘 먹이고 가르쳐야 쓸 만해진다.

## 데이터

- 사람마다 유전자 배열을 고정 크기 바이트로 저장한다. 특성 30개 × 쌍 → 수십~수백 바이트.
- 수만 명이어도 수 MB 수준이다.
