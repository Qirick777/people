# 농사

인간의 기본 식량은 농사로 얻는다. 아래 요소만 규칙으로 두고, 나머지는 사람들의 행동에서 나오게 한다.

## 땅

| 값 | 정해지는 방식 |
|---|---|
| 비옥도 | 세계 생성 때 정해진다. 강가와 범람원이 높다. 경작하면 줄고, 쉬게 두면 회복한다. |
| 물 | 강, 호수와의 거리, 강수량. 물길을 파서 끌어올 수 있다. |
| 기후 | 위도와 고도로 정해진다. 작물마다 맞는 기온이 다르다. |

비옥도와 물 때문에 사람들은 저절로 강가에 모여 산다. 마을 위치가 지형에서 나온다.

## 한 해의 일

1년 = 4계절. 계절마다 해야 할 실제 행동이 있다.

| 계절 | 일 |
|---|---|
| 봄 | 땅 갈기, 씨 뿌리기 |
| 여름 | 김매기, 물 대기 |
| 가을 | 수확, 운반, 저장 |
| 겨울 | 저장한 식량으로 버티기, 도구 손질 |

- 일은 사람이 직접 한다. 때를 놓치면 수확이 준다. 씨 뿌릴 때 일손이 모자라면 그해 수확이 작다.
- 힘, 성실함, 농사 경험(일하며 늘어난다)이 일의 속도와 질을 정한다.
- 날씨는 해마다 흔들린다. 가뭄과 홍수가 흉년을 만들고, 흉년이 불만과 쿠데타로 이어진다.

## 저장

- 수확물은 실제로 옮겨서 창고에 둬야 한다.
- 시간이 지나면 상한다. 창고 상태와 관리하는 사람의 꼼꼼함이 속도를 정한다.
- 창고는 훔치거나 빼돌릴 수 있다. 감시가 필요하다.

## 땅의 주인

- 가구가 자기 땅을 부치고 일부를 세금으로 내는 방식
- 영지 땅을 농사 묶음이 부치고 수확을 영지가 가져가는 방식

두 방식 모두 묶음 시스템으로 표현된다. 섞어 쓸 수도 있다.

## 처음에 넣을 것

- 작물 두세 종류 (곡물 하나, 채소 하나 정도)
- 비옥도 감소와 회복. 휴경과 돌려짓기는 규칙으로 넣지 않는다. 사람들이 비옥도 변화를 보고 스스로 하게 만든다.
