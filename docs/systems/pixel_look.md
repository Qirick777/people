# 도트 그래픽 흉내 (3D → 저해상도)

시안 이미지: `docs/images/pixel_*.png`, `docs/images/pixel_pan_compare.gif`
시안 코드: `prototypes/pixel_look/render_pixel.gd`

## 방식

1. **저해상도 렌더**: 3D 장면을 SubViewport에 480×270으로 그린다.
2. **최근접 확대**: 정수배(3배, 4배)로 키우고 최근접 필터를 쓴다. 픽셀 경계가 또렷하게 남는다.
3. **텍스처도 최근접**: 재질의 텍스처 필터를 최근접으로 바꿔 무늬가 뭉개지지 않게 한다.
4. **카메라 텍셀 맞춤**: 카메라 위치를 화면 평면(오른쪽, 위 방향)에서 텍셀 크기 단위로 반올림한다.
   카메라가 픽셀 단위로만 움직이므로 정지한 물체의 픽셀이 매 프레임 같은 모양을 유지한다. 기어가는 현상이 사라진다.
5. **오차 보정**: 반올림으로 남은 1픽셀 미만 오차만큼 확대한 화면을 밀어 준다. 그래서 스크롤은 부드럽다.
   저해상도에 여유(사방 4픽셀)를 두고 렌더해서, 밀어도 가장자리가 비지 않게 한다.

텍셀 크기 = 직교 카메라 세로 크기 ÷ 저해상도 세로 픽셀 수

## 조건

- 카메라 각도는 고정이어야 한다. 회전하면 모든 픽셀이 다시 계산되어 기어간다. (좀보이드식 고정 시점과 맞는다)
- 확대·축소는 정해진 단계로만 한다. 단계마다 텍셀 크기가 정수배로 떨어지게 잡는다.
- 움직이는 물체(걷는 사람)는 여전히 픽셀이 흔들린다. 물체 위치도 텍셀 격자에 맞추면 줄어든다.
- 그림자도 카메라와 함께 맞춰야 떨림이 없다.

## 더 도트답게 하려면

- **텍스처를 단순하게**: 지금 텍스처의 잔노이즈가 저해상도에서 지저분한 점으로 보인다. 도트는 평평한 색 면이 기본이다.
- **팔레트 제한**: 색 수를 32~64색으로 줄인다. 자동 감색은 지붕의 빨강, 옷의 파랑 같은 포인트 색을 지워 버려서 결과가 나빴다.
  팔레트를 직접 정해 두고 셰이더에서 가장 가까운 색으로 바꾸는 방식이 맞다.
- **외곽선**: 깊이와 법선 차이로 가장자리를 찾아 한 픽셀 선을 그린다. 물체가 배경에서 또렷하게 분리된다.
- **조명 단계화**: 명암을 3~4단계로 끊으면 손으로 찍은 도트의 음영처럼 보인다.

## 성능

- 저해상도로 그리므로 화면 픽셀 수가 1/9~1/16로 준다. 픽셀 셰이더 비용이 크게 준다.
- 수만 명 규모에서 그리기 부담을 줄이는 데도 유리하다.
