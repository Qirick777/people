# 기획 초안

## 한 줄 콘셉트

인간들을 세계에 풀어 놓고, 그들이 스스로 번식하고 살아남고 사회를 이루는 과정을 지켜보는 관찰형 시뮬레이션.
화면은 좀보이드처럼 비스듬한 탑뷰로 본다.

## 핵심 축

| 축 | 내용 |
|---|---|
| 인간 | 특성을 가진다. 자식에게 특성을 물려준다. |
| 사회 | 가족, 무리, 마을이 저절로 생긴다. |
| 건축 | 정해진 디자인 몇 개를 바탕으로 변형을 많이 만든다. |
| 지형 | 강, 숲, 나무, 바다, 호수. |
| 맵 | 몰입을 해치지 않게 넓어진다. |

## 구조 원칙

1. **시뮬레이션과 화면을 분리한다.** 시뮬레이션은 노드 없이 순수 데이터로 돌린다. 화면은 카메라 근처만 그린다.
2. **거리별로 시뮬레이션 정밀도를 나눈다.** 카메라 근처는 걸음 단위, 먼 곳은 하루 단위 요약 계산으로 돌린다.
3. **특성은 생존과 번식에 영향을 줘야 한다.** 영향이 없으면 유전이 의미 없다.
4. **유전 특성과 문화 특성을 나눈다.** 체격, 기질은 유전한다. 건축 양식, 관습은 배워서 전한다.
5. **지형은 두 단계로 만든다.** 넓은 범위의 대략 지도(대륙, 강줄기)를 먼저 만들고, 청크별 세부를 나중에 채운다. 그래야 강이 청크 경계에서 끊기지 않는다.
6. **건물은 틀 + 변수로 만든다.** 틀(평면 구성) 몇 개에 크기, 재료, 지붕, 증축, 낡음, 주인 성향을 변수로 붙인다. 재료를 주변 자원에서 고르면 지역마다 양식이 저절로 달라진다.

## 정해야 할 것

1. 시간 배율: 한 세대를 실제 시간으로 몇 분에 볼 것인가
2. 목표 인구 규모: 수십, 수백, 수천
3. 플레이어 개입 범위: 순수 관찰, 가벼운 개입, 신 권능
4. 맵 확장 방식: 처음부터 큰 세계를 탐험, 인간이 퍼질 때 세계가 열림
5. 문명 발전: 원시 수준에 머무는가, 기술이 발전하는가

## 첫 프로토타입 범위 (제안)

작은 섬 하나에 인간 열 명을 풀어 놓는다.
배고픔과 짝짓기만 있고, 특성 두세 개가 유전된다.
