# 기획 초안

## 한 줄 콘셉트

(미정) 좀보이드처럼 위에서 비스듬히 내려다보는 생존 게임.

## 좀보이드에서 가져올 핵심 요소 후보

- 비스듬한 탑뷰 시점과 건물 층 구조 (지붕/위층 가림 처리)
- 시야 원뿔과 소리로 적을 인지하는 구조
- 배고픔, 갈증, 피로, 부상 같은 생존 수치
- 무게와 칸을 쓰는 인벤토리, 바닥에 놓인 물건 줍기
- 파밍, 제작, 거점 꾸미기
- 오래 버틸수록 나빠지는 세계 (전기·수도 끊김 등)
- 한 번 죽으면 끝나는 긴장감

## 결정해야 할 것

1. 시점 구현 방식: 2D 아이소메트릭 타일 vs 3D 모델 + 직교 카메라
2. 게임의 차별점 (적, 배경, 목표)
3. 첫 프로토타입 범위
4. 스크립트 언어: GDScript vs C#
5. 아트 방향
6. 싱글 / 멀티

## 첫 프로토타입 범위 (제안)

방 몇 개짜리 맵 하나에서 캐릭터가 걷고, 벽에 가린 곳이 안 보이고, 적 하나가 소리를 듣고 쫓아온다.
이 셋이 되면 시점 방식이 맞는지 판단할 수 있다.
